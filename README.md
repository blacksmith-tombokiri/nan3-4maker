# 終盤局面メーカー

南3局・オーラスの点棒状況を生成し、終盤の条件戦を練習するためのWebツールです。

「普通に半荘を打っているだけでは遭遇回数の少ない終盤局面を、短時間で繰り返し考えられるようにする」ことをコンセプトとして、blacksmith-tombokiri が企画・制作しています。
